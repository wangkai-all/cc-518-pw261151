# SLA 违约根因分析工具

把**数据延迟、任务依赖、资源等待、业务影响**串成可审计的根因链：一个违约可由多个上游
共同造成，系统区分「证据充分 / 高度疑似 / 待确认」原因，支持新增证据后重算影响，
且**重算永不覆盖人工判断**。

零运行时依赖（仅用 Node 内置模块与浏览器原生 API），含 43 个单元/集成测试。

## 启动

```bash
npm start                 # http://localhost:3000
node server.js --port 3210 --reset   # 自定义端口并用种子数据重建
npm test                  # 运行全部测试
```

首次启动自动从 `data/sample-data.json` 播种，运行状态持久化在 `data/store.json`。

## 页面功能

| 页签 | 内容 |
| --- | --- |
| ⏱ 时间线 | 每个违约一个区块，全部事件先归一到 UTC 再排序；同时展示事件原始本地时间与时区；重复事件半透明折叠，DST 缺口/回拨事件挂告警标签 |
| 🔗 依赖图 | 分层 SVG 依赖图，`A → B` 表示 A 依赖 B，故障沿反方向传播；虚线为非关键路径；可从根因候选一键高亮传导链 |
| 🧭 根因候选 | 按评分排序的候选列表，三级证据分级、支撑证据明细、贡献分钟数、传导路径；支持人工确认/排除（黏滞） |
| 🛠 处置状态 | 五态状态机（待处理→排查中→已缓解→已解决/已接受），非法迁移后端拒绝，全量流转留痕，支持负责人指派 |
| 🗂 版本对比 | 每次重算生成不可变版本快照，任意两版对比新增/消失/变化候选，明确标出人工判定未被覆盖的条目 |

顶栏可切换**展示时区**（UTC / 上海 / 纽约 / 伦敦），所有时间瞬时不变、只换挂钟表达。

## 核心设计

### 1. 时区先行（`src/time.js`）

事件入库即把「本地挂钟时间 + IANA 时区/固定偏移」解析为 UTC epoch ms，原始字段保留审计：

- 枚举探针前后 24h 内出现过的全部 UTC 偏移，逐一反推候选并回映验证；
- **回拨歧义**（同一挂钟时间对应两个瞬间）：返回两个候选，默认取较早的夏令时侧；
- **前跳缺口**（挂钟时间不存在）：按时间流逝顺延到跳转后第一个有效瞬间；
- 固定偏移支持 `UTC+08:00`、`UTC-03:45` 这类半小时/45 分时区。

### 2. 重复事件识别（`src/dedup.js`）

同实体 + 同类型 + 同源（或相同 `fingerprintKey`，指纹跨来源系统全局匹配）+ 30 分钟窗内
+ 描述归一化相同 → 折叠为一组，只保留最早一条参与根因评分。
因此纽约 `20:05 UTC-5` 与 UTC `01:05` 的跨时区镜像告警会被正确归并。

### 3. 因果图与根因评分（`src/graph.js`、`src/engine.js`）

- 关系构建为有向图，Kahn 拓扑校验拒绝带环数据，报错给出具体环路径；
- 候选集 = 违约实体 + 全部祖先实体，证据必须**早于**违约瞬间且在 12h 窗口内；
- 评分 = 证据权重（失败 40、延迟/等待按时长加权、重试边际递减，上限 60）
  × 传导衰减 `0.92^跳数` × 路径关键性（关键 1.15 / 非关键 0.85）；
- 分级：关键路径且证据分 ≥32 → **证据充分**；≥8 → **高度疑似**；无直接证据 → **待确认**。

### 4. 重算不覆盖原判断（`src/store.js`）

```
新增证据 → 追加到原始数据 → 生成新版本不可变快照
人工判定（confirmed/rejected）永久继承 → strength 以人工为准，机器判断另存 machineStrength
不一致时置 machineDiffers，在页面显式暴露分歧
```

历史版本永不就地修改，版本 diff 可逐版审计每个候选的分数与强度变化。

## 目录结构

```
src/            纯引擎（可独立于 HTTP/UI 复用与测试）
  time.js       时区解析（DST gap/ambiguous）
  dedup.js      重复事件识别
  model.js      实体/关系/事件规范化与枚举
  graph.js      因果图、环检测、拓扑、可达路径
  engine.js     违约识别、根因评分、证据分级、版本 diff
  store.js      持久化、版本快照、人工判定黏滞、处置状态机
public/         原生 ESM 前端（无框架、无构建）
tests/          node:test 测试（43 个）
server.js       零依赖 HTTP 服务 + REST API
data/           种子数据与运行时存储
```

## REST API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/case` | 首屏完整视图 |
| POST | `/api/events` | 追加证据事件并重算（重复 id 拒绝） |
| POST | `/api/judgments` | 人工确认/排除根因候选 |
| POST | `/api/remediation/:breachId/transition` | 处置状态流转 |
| POST | `/api/remediation/:breachId/assign` | 指派负责人 |
| GET | `/api/versions/:n` | 历史版本快照 |
| GET | `/api/diff?from=1&to=2` | 版本结构化对比 |
| POST | `/api/reset` | 用种子数据重建 |
